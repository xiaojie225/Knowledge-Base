# 微信订阅消息开发速查表

## 1. 核心流程 (三步走)
1. **获取模板ID**: 登录微信公众平台 → 功能 → 订阅消息 → 添加模板。
2. **调起授权**: 调用 [`wx.requestSubscribeMessage()`](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/subscribe-message/wx.requestSubscribeMessage.html) 接口。
3. **服务端发送**: 调用服务端 `subscribeMessage.send` 接口推送消息。

---

## 2. 关键 API 代码速查

### 2.1 调起授权 (`wx.requestSubscribeMessage`)
```javascript
wx.requestSubscribeMessage({
  tmplIds: ['模板ID1', '模板ID2'], // 最多3个
  success(res) {
    // res: { '模板ID': 'accept' | 'reject' | 'filter' }
    console.log('订阅结果', res)
  },
  complete() {
    // 无论成功失败，建议在此执行业务逻辑
  }
})
```

### 2.2 获取订阅设置 (`wx.getSetting`)
```javascript
wx.getSetting({
  withSubscriptions: true,
  success(res) {
    const { subscriptionsSetting } = res;
    // subscriptionsSetting.mainSwitch (总开关)
    // subscriptionsSetting.itemSettings (模板详细状态)
  }
});
```

### 2.3 云函数发送消息 (wx-server-sdk)
```javascript
const cloud = require('wx-server-sdk');
cloud.init();
exports.main = async (event) => {
  return await cloud.openapi.subscribeMessage.send({
    touser: 'OPENID',
    templateId: 'TEMPLATE_ID',
    page: 'pages/index/index',
    data: {
      thing1: { value: '订单号:123' },
      time2: { value: '2025-01-20 10:30' }
    }
  });
};
```

## 3. 实现模式与最佳实践

### 3.1 业务结合推荐模式
**先订阅后提交**：确保业务逻辑在 `complete` 回调中执行，保证流程不中断。
```javascript
_onRequestSubscribeMessage((callback) => {
  wx.requestSubscribeMessage({
    tmplIds: [...],
    complete: () => {
      callback && callback(); // 无论用户是否授权，正常执行后续逻辑
    }
  });
});
```

### 3.2 智能提示与防骚扰
*   **频率限制**: 同一用户建议 24 小时内只提示一次（使用 `wx.setStorageSync` 记录时间）。
*   **触发要求**: 必须由用户点击事件触发。

## 4. 常见错误码对照表

| 错误码 | 含义 | 处理建议 |
| :--- | :--- | :--- |
| 20001 | 模板ID不存在 | 检查模板ID准确性 |
| 20003 | 模板数量超限 | 一次最多订阅3个 |
| 20004 | 用户关闭主开关 | 引导用户前往设置页开启 |
| 43101 | 用户拒绝或取消订阅 | 正常逻辑走下去，不影响业务 |
| 47003 | 参数不匹配 | 严格对照模板字段格式 |
